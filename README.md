# Zyntra Security — Enterprise Cybersecurity Homelab

## Project Overview

Zyntra Security is an enterprise-style cybersecurity and IT infrastructure homelab designed to simulate a corporate environment.

This project demonstrates hands-on experience in Windows Server administration, Active Directory, hybrid identity management, network security, security monitoring, endpoint protection, and authorized penetration testing.

## Technical Skills

- Windows Server 2025 Administration
- Active Directory Domain Services (AD DS)
- DNS and DHCP
- Group Policy Management
- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Microsoft Entra ID and Cloud Sync
- Security Information and Event Management (SIEM)
- Network Security and Firewall Administration
- PowerShell Automation
- Vulnerability Management
- Security Incident Investigation

## Key Accomplishments

- Built and configured an Active Directory environment from scratch.
- Created 50 employee accounts across seven organizational departments.
- Implemented departmental security groups and least-privilege access controls.
- Configured centralized file shares and NTFS permissions.
- Implemented Group Policy configurations.
- Deployed a dedicated Microsoft Entra Cloud Sync server.
- Successfully synchronized pilot on-premises identities to Microsoft Entra ID.
- Deployed Wazuh for centralized security monitoring.
- Configured pfSense to manage and protect the virtual network.
